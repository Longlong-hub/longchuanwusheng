# 龙川武生 · 诗与代码

个人网站：https://longlong-hub.github.io/longchuanwusheng/

诗词、思考、医学科普与 AI 创意。

`main` 保存发布流程和经作者选定的公开文件清单。发布流程按 SHA-256 校验每个文件，为项目地址调整图片、导航和诗集路径，将完整网站副本保存到 `gh-pages`，再部署到 GitHub Pages。

首次启用：在 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。之后更新发布清单或手动运行 Actions，即可发布选定版本。

已经发布的网站副本保存在本仓库中，不依赖原站实时转发。正文与图片的来源标注随原文保留。
