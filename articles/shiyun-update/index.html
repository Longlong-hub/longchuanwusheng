诗云焕新｜给文字，一方更安静的天地

文 / 龙川武生发布于 2026-10-28约 3 分钟
创造 · 诗云界面更新
诗云焕新
给文字，一方更安静的天地
文 / 龙川武生
上次介绍诗云时，我想做的事情很简单：把散落在文学库里的文字重新带到眼前，看看它们的字，也读读它们的心。
最近，我又整理了一次它的界面。
「品」与「赏」还是阅读的中心。这次想解决的是，打开网页之后，眼睛先落在哪里，下一步该点什么，以及读一首诗时，周围能不能安静一点。
一
从暖色旧纸，走到纸白与松绿
旧版诗云的「品」页，取自此前项目介绍所用截图。这里用于回顾旧版视觉，并非同一首诗的性能或效果对照。
旧版用暖黄纸色、红色印章按钮和居中的大标题，古意很直观，也有它的热闹。
新版把底色收得更淡，用松绿色标识主要动作，给区域之间留出更多空隙。山水插画放在欢迎画面里，像是一扇窗，打开之后再把位置让给诗。
本次改版界面：顶部品牌和设置、左侧诗集与导入、右侧阅读主画布；图片取自项目的新版界面截图。
我希望人第一眼看见的，是「给文字，一方天地」，然后自然地找到自己的作品。诗云想留住的文学感，可以从字与留白里慢慢出来。
二
左边找诗，右边慢慢读
诗云这次界面整理的三个层面：视觉、结构与反馈 · 原创对照图
这次最明显的结构变化，是把操作收进侧栏，把更完整的区域留给阅读。
左侧的「我的诗集」放作品与赏析数量，可以选一首，也可以随机赏一句。导入 Markdown 文件、导入目录这些入口，也集中在这里。
右侧是主画布。「品 · 词云」和「赏 · 诗句」放在同一条工具栏上，切换时，阅读区域的位置更稳定。
三个常用动作
想找特定作品，先在左侧选诗；想随意逛逛，就随机赏一句；想带来新文字，使用导入文件或目录。正文和赏析留在右侧慢慢看。
这些能力有些原来就有。这次改版更多是在重新安排它们的位置和层次，让第一次打开的人少猜一点。
三
空的时候，也知道从哪里开始
一个本地文学工具，未必一打开就已经读到了诗集。
新版给了更明确的欢迎画面与「开启一卷诗意」入口。有作品时可以进入阅读，没有作品时，会引导导入文件。读取或切换时，也有状态提示。
这对熟悉程序的人也许只是几行文案，对第一次用的人，却关系到会不会以为「是不是坏了」。我想把这种困惑少留一点。
四
读诗之外，那些小动作也整理了
设置窗口现在有更明确的关闭方式。键盘焦点会留在窗口里，按 Escape 可以退出，关闭后回到原来的触发位置；背景区域在窗口打开时暂停交互。
保存配置时，按钮会显示处理状态。已经保存的 API Key 也不会直接重新填进输入框，而是提示留空保留。
这些改动很琐碎，却影响实际使用时的踏实感。当然，输入框不回显 Key 只是一处界面处理，不能由此推断整套服务已经经过安全审计。
窄屏布局也做了调整。不过这篇介绍依据的是实际源码和项目截图，我还不会把它写成「所有手机与浏览器都已经适配完美」。真实设备的反馈，仍然值得继续收。
五
仓库已经同步，可以直接看新版
这次顺便核对了本地项目和 GitHub。
核对时，本地工作区没有未提交改动；本地 HEAD 与远程 main 一致，都是 044f036。 这条提交的内容，就是纸白与松绿界面改版。
变更主要落在页面、新增的样式文件、山水插画和新版界面图中。服务端与知识库规范文件没有在这条提交里变化，所以这次主要是前端阅读体验的整理。
已有克隆的朋友，可以先确认自己的修改已经保存，再拉取更新。第一次尝试的朋友，仍可从仓库 README 开始，准备 Node.js 与自己的 Markdown 文学库。
项目：Longlong-hub / Literature-Vault
本次改版：044f036
六
让自己愿意再打开一次
我做诗云，是因为有些写过的字，值得被自己再读一遍。
这次界面整理，也是往这个方向挪一点。找到诗更顺手，周围更安静，读的时候就更容易多停一会儿。等某天忽然在一首旧作里看见从前的自己，这些调整也就有了用处。
如果你愿意试试新版，欢迎告诉我：哪里读得舒服，哪里还让你分心。我们再慢慢改。
