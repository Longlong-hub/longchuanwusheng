皮肤性病学入门（三）· 治与防的逻辑闭环
本篇主线：诊断回答的是"这是什么病"，治疗要回答的是"为什么这样治才有效"。本篇用一条主线串起两章——把病理机制翻译成用药原理（第七章：治），再把"治"的尽头接到"防"（第九章：防）。贯穿全程的是一句显性的因果链：皮损处于什么状态、机制上"缺什么、多什么"，药就补什么、抑什么。

引子：诊断之后，还有一道"翻译题"
上一篇我们把"说得准"这件事讲完了——形态不等于病因，得靠检查与程序去收敛结论。可诊断只是上半场。真正的下半场是这个页面里最容易被忽略的一句："知道是什么病，不等于知道该抹什么。"
举个每位读者都可能踩过的坑：脸上忽然一片红肿、还往外渗水，于是有人顺手涂上一层厚厚的护肤软膏——第二天更肿、更渗，甚至"沤"出一层白皮。药没买错，错在剂型。因为在"渗出"这个状态下，最该做的事情恰恰是让水出去，而软膏最擅长的却是把水闷住。
这一篇要讲的，就是皮肤科治疗里最讲逻辑、也最讲"机制闭环"的部分：皮损的状态决定用药的形态，用药的形态又由物理学与药理学原理决定。把这条链讲通，"治"（第七章）和"防"（第九章）就自然接上了——治是纠正当下的机制偏差，防是别让偏差再发生。
带着这个出发点，我们开始第三讲。
一、治疗的底层逻辑：为什么皮肤科格外倚重"抹药"
教材把皮肤科的治疗归为四大类（《皮肤性病学》第10版 P72）：
治疗方法给药/作用方式典型场景
局部治疗药物直接涂于皮损本学科特有方法，多数皮病首选
系统治疗口服、肌注、静注泛发、重症、累及全身
物理治疗光、电、冷、热等非药物手段限局、表浅、顽固皮损
皮肤外科切、植、磨、摘手术肿瘤切除、取材、修复
治疗要有整体观念：先分清"是单纯皮肤病变，还是合并了其他系统病变"，再据此做个体化方案——这是教材开篇就强调的态度（P72）。
1.1 经皮吸收：局部治疗的物理学根基
为什么皮肤科敢把药"只涂一层"就指望有效？答案藏在皮肤最本职的功能里——屏障。
机制 ·结构决定功能：皮肤是人体最外在的器官，角质层像一层致密的"城墙"，把绝大多数外物挡在外面。于是外用药物有一个天然的分配结果——局部药物浓度高、系统吸收少。翻译成人话：该治的地方药够浓，不该去的地方药不多，较高局部疗效 + 较少系统不良反应。这就是"经皮吸收"（percutaneous absorption）成为局部治疗理论基础的逻辑。
药物能不能"翻墙"、翻多少，教材列出五项影响因素：① 皮肤角质层厚度；② 药物分子量大小；③ 药物浓度；④ 用药时间长短；⑤ 外用药物基质类型（P72）。
辨析 ·这五项里，"基质类型"最容易被忽略，却最能解释后面所有剂型选择的道理——同样一克药，"泡在水里""和油乳化""捏进凡士林"，透皮能力和作用方式完全不同。先记住：剂型不是包装，是给药方式的载体。
二、局部治疗：把机制翻译成"药"
局部治疗要做两个决策，且顺序不能颠倒：先用"病因与发病机制"定下药种，再用"皮损特点"定下剂型。
2.1 第一步：按病因选"种类"——病因决定药种
教材表 7-1 把外用药物按作用分了十几类（P72～73）。不必背全表，抓住"病因 → 药种"的映射即可：
致病机制/病因对应药种代表药物
渗出物、鳞屑、痂皮、残留药清洁剂生理盐水、3%硼酸溶液、1:1000 呋喃西林溶液
蛋白质外渗、分泌亢进收敛剂0.2%～0.5% 硝酸银、2% 明矾液
神经末梢受刺激（痒）止痒剂1% 苯酚、焦油制剂、糖皮质激素
角化不全（增生活跃）角质促成剂2%～5% 煤焦油、3% 水杨酸、3%～5% 硫黄
角化过度（增厚堆积）角质剥脱剂5%～10% 水杨酸、20%～40% 尿素、维A酸
细菌感染抗细菌剂莫匹罗星、夫西地酸
真菌感染抗真菌剂克霉唑、酮康唑、特比萘芬
炎症/免疫反应糖皮质激素、维A酸类、生物制剂见 §2.3
机制 ·同一种成分、浓度不同，药种会"跨界"——这正是机制决定用途的典型。3% 水杨酸只够促进角质层正常化（角质促成剂），5%～10% 水杨酸才能松解、剥脱过度角化的细胞（角质剥脱剂）。浓度不是"越高越好"，而是要"调机制所需的那一档"。
2.2 第二步：按皮损状态选"剂型"——干湿决定形态（本篇核心）
如果说 §2.1 解决"用什么药"，§2.2 解决的是"把药做成什么"。教材用一条清晰的决策链给出答案，而这条链的唯一主线就是皮损的"干湿状态"（P73～74）。
图 D1 · 外用剂型选择决策链——剂型跟着皮损的"干湿状态"走（据《皮肤性病学》第10版 P73～74 第七章整理）
把上图压缩成一句口诀，正是系列反复强调的诀窍：
口诀 ·干对干、湿对湿，半干用乳糊；再简一号：急湿洗、亚乳糊、慢软硬——急性/亚急性/慢性三期的剂型速记。
为什么这么绕？因为每一条分支背后，都站着一条"因为…所以…"的机制链。
以"渗出"为例：为什么渗出多时，只能用溶液湿敷
这是决策链上最硬、也最常见的一个考点。皮损"糜烂渗出较多"时，答案只有一个——溶液湿敷（常用 3% 硼酸溶液、1:8000 高锰酸钾溶液、0.2%～0.5% 醋酸铝溶液）；此时软膏、洗剂、粉剂全都错。原因要分三层讲，缺一层就不算闭环：
第一层（物理）：3% 硼酸溶液是高渗溶液（浓度高于组织液），存在渗透压差 → 把组织间隙多余的水"吸"出来 → 直接减轻淤血与水肿。
第二层（清洁）：溶液是流动的，能冲走、溶解分泌物与痂皮 → 清除渗出物、痂和残留药物，让创面干净、透气。
第三层（药物）：若溶液含抗菌成分，还兼有抗菌消炎作用；同时湿敷本身靠蒸发散热，给炎症"降温"。
机制 ·渗出 = 组织液"漏"到了皮面。处理它的逻辑与"地上积水"一致：要高渗的"吸水剂"、要流动的"排水渠"。所以此处要的是"液体的形态"（湿敷）——而软膏会阻止水分蒸发、不利散热，等于"沤"住积水，故禁用于渗出期。
提醒 ·湿敷有操作规范，不是"拿药水随便抹"：需用 6～8 层纱布浸湿后拧至不滴水，平贴皮损，每次约 20～30 分钟，每日数次；渗出减少后即改用霜剂/乳剂。湿敷面积过大、时间过长需防受凉与药物吸收过量，儿童尤需注意。
生活场景 · 皮肤油、爱长痘，该选哪种剂型
核心思路：油性皮肤（尤其面部 T 区）的困扰，本质是"油多"——就别再补油，要选能融进水里、容易洗去的形态，同一条"干湿匹配"逻辑。

优先水包油（O/W）型乳剂：水为连续相 → 清爽、易洗去 → 专为油性皮肤设计；习惯上 O/W 型常被称作"霜"。

避开油包水（W/O）型：油为连续相 → 有油腻感 → 更适合干性皮肤或寒冷季节，油皮用易闷痘。

慢性油腻伴痤疮：可选凝胶（如过氧化苯甲酰凝胶、阿达帕林凝胶）——以高分子+有机溶剂为基质，涂后成薄层，凉爽润滑，急慢性皮炎均可使用，肤感最清爽。

别迷信"滋润"：油皮不需要额外加油；过度清洁、频繁去油反而破坏屏障，形成"外油内干"的恶性循环。
机制 ·"油性皮肤用 O/W 乳剂"不是商家的营销话术，而是剂型理化性质与皮肤生理状态的匹配：连续相相同者相容——水连续相（O/W）融于多水、多汗的油性皮面，油连续相（W/O）则适合因缺脂质而"干"的皮面。所谓"护肤要对症"，落到剂型层面，就是这一句。
2.3 外用糖皮质激素：强度分级与部位时程
糖皮质激素是皮肤科最重要的外用抗炎药，按强度分四级（P73）：
强度代表药物（常用浓度）
弱效醋酸氢化可的松（1%）、醋酸甲泼尼龙（0.25%）
中效丁酸氢化可的松（0.1%）、曲安奈德（0.025%～0.1%）、醋酸地塞米松（0.05%）
强效二丙酸倍他米松（0.05%）、哈西奈德（0.025%）、氟轻松（0.025%）
超强效丙酸氯倍他索（0.02%～0.05%）、卤米松（0.05%）、哈西奈德（0.1%）
口诀 ·弱氢化、中曲安、强倍他、超氯倍——四级代表药速记。
强度的"副作用"同样遵循机制：局部可出现皮肤萎缩、毛细血管扩张、紫癜、多毛、毛囊炎、色素异常，还可增加致病微生物感染机会（P73）。所以教材给出两条"部位与时程"规则：
部位：面部、乳房、腋下、外生殖器等部位皮肤结构特殊 → 对激素吸收力较强 → 须注意用药强度与时程，宜选弱效或钙调磷酸酶抑制剂，连续疗程一般不超过 2～4 周。
时程与人群：大面积、长时间外用强效激素或封包治疗 → 可发生系统性不良反应；婴儿体表面积相对较大 → 外用激素应重视系统不良反应出现的可能性。
机制 ·为什么"薄嫩部位"要用弱效？因为经皮吸收的五因素里，角质层厚度排第一——面部、皱褶处角质层薄，"城墙"矮，药物更容易翻墙入血。单位面积吸收多，则局部与系统副作用都会被放大。强度选择本质上是"用皮肤厚度反推安全剂量"。
2.4 外用药物治疗原则：教材的三步框架
以上内容，教材最后收敛成一个答题三步法（P74），也是本文第二条主线：
步骤要选什么依据
① 正确选用种类抗菌药／抗真菌药／糖皮质激素或钙调磷酸酶抑制剂／止痒剂／角质促成剂／角质剥脱剂病因与发病机制
② 正确选用剂型溶液／粉剂／洗剂／乳剂／糊剂／软膏／硬膏……皮损特点（干湿决策链）
③ 详细解释用法与注意事项使用方法、时间、部位、次数、可能不良反应及处理方法年龄、性别、既往用药反应
提醒 ·处方后不解释用法，是治疗失败最常见的隐形原因：洗剂须"用前摇匀"，湿敷须"定时、拧干"，强效激素须"限部位、限疗程"。同时应告知：若涂药后红肿灼痒反而加重，可能是刺激或致敏，应停用可疑药物并记录。
三、系统治疗：当"抹"解决不了，或病在全身
系统治疗靠"药进全身"来治病。教材列出的常用系统药物有抗组胺药、糖皮质激素、抗细菌/抗病毒/抗真菌药、维A酸类、免疫抑制剂等（P74）。抓三条主线即可。
3.1 抗组胺药：止痒的"受体逻辑"
痒是皮肤科最普遍的症状，其背后有明确的分子机制。教材指出：已鉴定的组胺受体有 4 种（H1、H2、H3、H4），其中 H1 受体主要分布在皮肤黏膜、血管及脑组织；皮肤微小血管同时存在 H1 与 H2 两种受体（P74）。
机制 ·组胺是瘙痒与风团的核心介质之一。它作用于皮肤血管的 H1 受体 → 引起毛细血管扩张（红）与血管通透性增高（水肿/风团），并刺激神经末梢（痒）。H1 抗组胺药竞争的正是这个位点：抢先占据 H1 受体 → 阻断上述效应 → 红、肿、痒同步减轻。它还兼有一定抗胆碱与抗 5-羟色胺作用。
按"能否透过血脑屏障"分两代，这是本章最经典的对比（P74～75）：
对比点第一代 H1 抗组胺药第二代 H1 抗组胺药
血脑屏障易透过 → 嗜睡、乏力、困倦、头晕不易透过 → 无明显或仅轻度嗜睡
抗胆碱作用明显 → 黏膜干燥、排尿困难、瞳孔散大较小
用法多需一日多次吸收快、作用长 → 一般每天 1 次
代表药氯苯那敏、苯海拉明、赛庚啶、异丙嗪氯雷他定、西替利嗪、非索非那定、依巴斯汀
口诀 ·一代嗜睡二不睡，驾驶青光一代躲——高空作业者、精细工作者、驾驶员禁用或慎用第一代；青光眼、前列腺增生者也需慎用。
辨析 ·慢性荨麻疹为何有时要加 H2 抗组胺药（西咪替丁、雷尼替丁、法莫替丁）？因为皮肤微小血管上 H1、H2 两种受体并存，只堵 H1 未必堵得住全部血管反应，联合才更稳。H2 药主要抑制胃酸分泌，兼有抑制血管扩张与抗雄激素作用（P75）。
生活场景 · 皮肤发痒，到底该怎么处理
先找因（二级预防的"早诊断"）：瘙痒可以是独立发生（老年性瘙痒、冬季瘙痒），也常继发于炎症性、超敏反应性、感染性、肿瘤性或代谢性疾病。教材强调"寻找病因尤为重要"——只止痒不查因，往往反复。

再止痒：明确为过敏/荨麻疹类 → 第二代 H1 抗组胺药（不嗜睡，白天可用）；夜间瘙痒影响睡眠 → 可酌情用第一代（借其嗜睡助眠，但驾驶员等禁用）；顽固性瘙痒在治疗原发病基础上，还可外用麻醉剂、辣椒素或多塞平软膏，口服 SSRIs 或三环类抗抑郁药，光疗亦有助缓解。

护屏障（防复发）：任何原因引起的瘙痒都应避免搔抓、忌刺激与烫洗。老年性、冬季瘙痒的机制正是"皮肤缺乏脂质" → 处理是补充含脂质的润肤剂（沐浴后及时涂抹），而不是频繁清洗或热水烫洗——烫洗会进一步带走脂质，越洗越痒。
机制 ·搔抓—瘙痒存在"恶性循环"：搔抓 → 机械损伤与炎症介质释放 → 更痒 → 更抓；热水烫洗 → 溶解并带走角质层脂质 → 屏障更弱、水分更易流失 → 更干更痒。所以止痒的终极手段是"切断循环"，而非加大力度去对抗它。
3.2 系统糖皮质激素：剂量分级与"反跳"
系统糖皮质激素作用谱广——抗炎、免疫抑制、抗细胞毒、抗休克、抗增生（P75）。适应证集中在三类：超敏反应性（重症药疹、严重荨麻疹、过敏性休克等）、自身免疫性（SLE、皮肌炎、天疱疮等）、严重感染性（须在有效抗生素前提下短期使用）（P75）。
剂量以泼尼松为例分五档（P76）：
剂量档泼尼松量效应适用
小剂量≤7.5mg/d约 50% 受体占有率维持治疗
中等剂量>7.5 且 ≤30mg/d50%～100%较轻疾病
大剂量>30 且 ≤100mg/d达 100%，完全基因组效应自身免疫病、重症药疹
超大剂量>100mg/d100% + 非基因组效应严重疾病初始治疗
冲击剂量>250mg/d，一般≤5 日以非基因组效应为主危重（狼疮脑病、重症天疱疮）
使用要点两条：短疗程一般不超过 3 周；长期使用者递减到维持量时，可采用隔天早晨顿服，以减轻对下丘脑-垂体-肾上腺（HPA）轴的抑制（P76）。
辨析 ·反跳现象（rebound phenomenon） ≠ 药物无效。它指的是：长期应用过程中不适当停药或减量过快 → 原发病反复或病情加重。所以激素"停"比"用"更考验经验——必须递减，不能骤停。

四、物理治疗与皮肤外科：不开药的"另一只手"
4.1 物理治疗的三条原理线
光疗：紫外线（UVB 290～320nm、UVA 320～400nm）可加速循环、抑制细胞过度生长、镇痛止痒、促色素生成与上皮再生（P80～81）。其中窄谱 UVB（NB-UVB，311～313nm）是白癜风一线疗法，有效率 75% 以上；308nm 准分子光光斑小，适合限局皮损；UVA1（340～400nm）诱导凋亡、抑胶原合成，用于特应性皮炎、硬皮病。
光动力疗法（PDT）：光敏剂（如 ALA）在病变组织聚集 → 特定波长光照激发 → 产生单态氧/自由基 → 病变组织坏死而正常组织损伤小（P81）。用于光线性角化病、Bowen 病、基底/鳞状细胞癌及病毒疣、痤疮。
冷冻疗法：以液氮（−196℃）冷冻 → 细胞内冰晶形成、细胞脱水、脂蛋白变性、局部循环障碍 → 组织坏死（P81）。用于各类病毒疣、化脓性肉芽肿、结节性痒疹。
机制 ·物理治疗与药物治疗的差别，在于"用什么样的能量去改变细胞命运"：光疗用特定波长"唤醒或抑制"细胞（如诱导 T 细胞凋亡），冷冻用低温"直接冻杀"病变细胞。二者共同点是作用局限、保留正常组织——这正是它们适合限局皮损的原因。
4.2 皮肤外科：切得"干净"的量化标准
皮肤外科用于肿瘤切除、创伤清理、活体取材与美容整形（P81～82）。其中值得一提的是 Mohs 显微描记手术：切除组织多点取材、即刻冷冻切片病理检查，据结果决定下一步切除范围 → 使体表恶性肿瘤（基底细胞癌、鳞状细胞癌等）的根治率显著提高。
机制 ·Mohs 的价值在于把"切"和"验"合为一体——每切一层就验一层，直到切缘无肿瘤为止。它用"病理证据"替代"经验估计"，本质上是把手术做成了可量化、可复查的过程。
五、预防与康复：把"治"的尽头接到"防"
皮肤病与性病的特点是发病率高、易复发，可影响生活质量甚至危及生命，因此预防发生与复发极为重要（P87）。第九章用"八类疾病 × 预防/康复"的矩阵来组织内容。

类别核心预防措施

瘙痒性皮肤病寻找病因尤为重要；补含脂质润肤剂；避免搔抓、忌刺激与烫洗
物理性皮肤病日晒伤/多形性日光疹→避日晒；痱/疖→避高温少出汗；冻疮→保暖；鸡眼胼胝→宽松鞋
皮肤肿瘤避开紫外线、电离辐射、致癌化学物与砷剂、慢性炎症刺激；癌前/可疑病变"三早"
炎症性皮肤病银屑病受上呼吸道感染、吸烟、饮酒影响 → 避免可减少复发
性传播疾病安全性行为（安全套、固定性伴）+ 高危人群定期健康教育与管理
5.3 八类疾病的康复要点
总前提：生活环境与生活习惯重要，心理因素也重要——医师不仅要治疗疾病，还需进行心理疏导（P88）。
类别康复要点
感染性针对感染的致病菌进行治疗
超敏反应性避开变应原；针对性查找致敏物而不盲目"忌口"；酌情用斑贴试验/点刺试验
职业性因人而异；职业性接触性皮炎可用激素、钙调磷酸酶抑制剂
瘙痒性重点在明确诊断；顽固者可用外用麻醉剂/辣椒素/多塞平，口服 SSRIs/三环类，光疗
物理性光敏性→避日晒 + 避光敏感食物；干燥相关→沐浴后用保湿/润肤/屏障修复剂
皮肤肿瘤按分类与转移情况制订方案；必要时多学科协作
炎症性按种类与严重程度：外用 + 系统（传统药物、光疗、生物制剂、小分子靶向药）
性传播疾病科学治疗 + 社会支持（不歧视、保护隐私）+ 性伴同诊同治
辨析 ·斑贴试验查的是 Ⅳ型（迟发型）变应原，点刺试验查的是 Ⅰ型（速发型）变应原。两法并列出现时勿混——前者适用于接触性皮炎的致敏物排查，后者适用于速发过敏（如荨麻疹、过敏性鼻炎）。
辨析 ·超敏反应性皮肤病的康复强调 "不盲目忌口"——正确路径是用斑贴试验/点刺试验针对性找出变应原，而不是把所有食物都戒掉。盲目忌口既无助于病情，还可能造成营养失衡。
5.4 康复三支柱
把上述要点归纳，康复其实是"三根支柱"共同用力（与全科医学"生物-心理-社会"模式一致）：
躯体康复：抗感染、光疗、保湿修复、手术/放化疗——解决"身体"的问题；
心理康复：心理疏导、减轻精神负担——解决"情绪"的问题；
社会康复：不歧视、宣教诊疗知识、保护隐私、性伴同诊同治——解决"环境"的问题。
提醒 ·性传播疾病的康复中，性伴同诊同治是最容易被忽略却最关键的一环：只治一方，未治的一方会成为持续的传染源，导致反复交叉感染。同时应保护患者隐私、消除歧视——这既是伦理要求，也是"社会康复"能落地的前提。

模块核心结论记忆钩子
治疗四大方法局部（特有）+ 系统 + 物理 + 外科局部是本学科"看家本领"
经皮吸收局部浓度高、系统吸收少（五因素：角质层厚度/分子量/浓度/时间/基质）皮肤是墙，药堆在墙外

选剂型（§2.2）皮损干湿决定剂型干对干、湿对湿，半干用乳糊

3%硼酸湿敷机制①高渗吸水退充血水肿 ②溶液清除分泌物及痂高渗吸水 + 流动冲洗

思考一 · "机制闭环"是皮肤科治疗的底层语法
回头看这一讲，从"经皮吸收"到"剂型决策链"，从"抗组胺作用于 H1 受体"到"补脂质润肤剂治干痒"，每一条用药建议都不是"经验之谈"，而是能原路追回到病理机制的。渗出用湿敷，是因为渗出本质是"水多了 + 脏了"；油皮用 O/W 剂型，是因为油多就该配水连续相的载体。当你能把处方"倒推"回机制，你就不是在背答案，而是在做医学推理。
思考二 · 治疗的尽头是预防——这是一个完整的闭环
第七章讲"怎么把病治好"，第九章讲"怎么让它别再来"。二者看似两件事，实则一体两面：治疗纠正的是当下已发生的机制偏差，预防阻断的是偏差再次发生的条件。药疹患者避"同类型结构相似药"，是因为交叉过敏的机制；银屑病人避上感、烟酒，是因为这些诱因会再次触发免疫紊乱。会治的人，也一定会防——因为预防，就是提前把机制偏差掐灭在萌芽之时。
提醒 ·本文为科普，旨在帮助读者建立"结构 → 功能 → 机制 → 表现"的医学思维，不构成诊疗建议。具体用药（尤其激素的强度、疗程、部位）务必遵医嘱；若皮损加重、出现系统症状，请及时就诊。本文不回复寻医私信。
