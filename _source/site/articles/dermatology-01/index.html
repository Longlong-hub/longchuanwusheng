皮肤性病学入门（一）：皮囊之内，形之于外
本篇主线：皮肤是人体的“第一道防线”。我们用一条主线串起四章：结构决定功能，机制反映于表现。读懂了“墙”是怎么砌的，就懂了“墙”破了会长成什么样子。

如果把人体比作一座城，皮肤就是最外围的城墙与哨所——它面积最大（成人约 1.5～2 m²，占体重 16%）、昼夜不休地替你挡住外界的风吹日晒、病原微生物与化学侵袭（《皮肤性病学》第10版 P28）。
但皮肤又不止是墙。它还是一块“显示屏”：身体内部出了什么状况，往往先在皮肤上“弹窗”。皮疹，常常是内在健康向外界发出的信号。
带着这个视角，我们开始第一讲。
一、皮肤病与性病：本是一家
1.1 它们是什么关系？
先厘清一个容易绕晕的概念：“皮肤性病学”“皮肤病学”“皮肤病和性病学”这几个名字，指向的是同一门学科。教材沿用《皮肤性病学》这一名称，而性病学之所以被纳入其中，逻辑非常清晰：
机制 · 因为多数性传播疾病的初期表现或主要受累器官是皮肤，所以性病学被并入皮肤病学范畴（《皮肤性病学》第10版 P25–26）。性病不是“另一门课”，它是皮肤病大家族里，因传播途径特殊而被单独拎出来讲的一支。

皮肤位于体表，既是人体第一道防线、直面外界环境，又与全身各系统密切关联——所以皮肤病的病因体系格外复杂（见图 1-2）：外有环境侵袭，内有系统性疾病牵连。

1.2 拓展思考
性病和皮肤病的“包含关系”，或值得一番思考，这里提供一些笔者的思考：
思考一 · 内病外显：“有诸内者，必形诸外”
性病的病原体（梅毒螺旋体、HPV、HIV 等）进入体内，悄悄在血液、神经、免疫系统中“安营扎寨”，但常常最先被看见的，却是皮肤黏膜。内在的感染与病变，终会在体表显形——这正是皮肤科医生把“皮损”当作窥见全身健康的窗口的根本原因。
思考二 · 隐秘与公示的反差
性行为发生在最私密的领域，而性病却偏偏选择在人人可见的皮肤上“公示”。这种“内隐而外显”的反差提醒我们：对性病，最忌讳的是因羞于启齿而拖延——皮肤已经替你“说”了出来，就别再替它“瞒”下去。
正因“隐”与“显”的反差，洁身自好始终是根本的防线——最好的治疗，是不给病原体可乘之机。古语“若要人不知，除非己莫为”，放到这里别有一番意味：私密之事，终究会在体表留下印记，身体不会替你保守有害的秘密。
思考三 · 潜伏的时间差
许多性病有长短不一的潜伏期：病原体已在体内繁殖播散，皮肤却风平浪静。这像一颗埋下的种子，还没冒头。窗口期与潜伏期的存在，正是“早筛查、早诊断、早治疗”的医学依据——别等皮肤“发芽”、身体报警才行动。
二、皮肤的结构与功能：一场“从婴儿到退休”的向上旅程
要读懂皮肤怎么生病，先得知道它的结构。这一节，分享一种动态的眼光来认识表皮，并联系五个生活场景。
2.1 三层楼的结构
皮肤由表皮、真皮、皮下组织构成，表皮与真皮之间以基底膜带相连（P28）。
图 2-1 · 皮肤解剖结构模式图（引自《皮肤性病学》第10版）
表皮：主要是角质形成细胞（占 80% 以上），像砖块一样层层叠起。
真皮：胶原纤维（抗拉）、弹力纤维（回弹）、基质（分子筛）与丰富的血管、神经、免疫细胞。
皮下组织：疏松结缔组织和脂肪小叶，缓冲、保温、储能。
机制 · 结构决定功能：真皮里纵横交错的胶原纤维像钢筋网，赋予皮肤“抗拉不断”的韧性；弹力纤维像弹簧，让皮肤拉伸后回弹。所以年轻人皮肤紧致，老年人弹力纤维退化，便松垮起皱——结构变了，功能（弹性）跟着变。
2.2 表皮五层：一个向上生长的“四代同堂”社会
表皮从深到浅分为五层（P57）：基底层 → 棘层 → 颗粒层 → 透明层 → 角质层。关键在于：这五层不是“五种不同的细胞”，而是同一种细胞——角质形成细胞——在不同年龄的样子。
图 2-2 · 角质形成细胞形态结构模式图（引自《皮肤性病学》第10版）
把表皮想象成一个向上生长的“社会”——它从最底层的“摇篮”一路向上，到最外层的“退休”。这个社会通常是“四代同堂”（掌跖等厚皮肤在颗粒层与角质层之间，还多一层“透明层”作缓冲），每一层年龄不同、各司其职、生生不息：
基底层 = 摇篮里的婴儿（再生源泉）：贴着真皮、呈立方形的一层细胞，约 30% 正在分裂。它们是表皮唯一的“产房”，不断向上输送新细胞；黑素瘤、基底细胞癌也起源于这一层。
棘层 = 儿童少年（手拉手的长身体阶段）：往上 4～8 层多角形细胞，像正在长身体的孩子。它们靠桥粒一个个“手拉手”连成片，内部的张力细丝（K1/K10）成束绷紧，既连得牢、又能随牵拉滑动；这里的增殖依然活跃。湿疹的“海绵形成”（细胞间水肿）、天疱疮的“棘层松解”都发生在这层。
颗粒层 = 青壮年（封墙的准备阶段）：1～3 层扁平梭形细胞，胞内塞满“透明角质颗粒”（含丝聚合蛋白原、角蛋白纤维、兜甲蛋白），同时向外排泌脂质前体。它像一个正在给墙“刷防水漆、抹灰浆”的师傅——屏障形成的物质基础就在这里奠定。
（仅掌跖厚皮肤）透明层 = 缓冲带：2～3 层无核扁平细胞，均质强折光，是厚皮肤的标志，在承受摩擦处起额外缓冲。
角质层 = 退休的老人（最终的砖墙）：5～20 层（掌跖 40～50 层）已经“死亡”的扁平细胞，细胞核消失、角蛋白填满、桥粒脱落——它们就是表皮最外那层致密“砖墙”，随时被新砖替下、剥落成皮屑。
而这个过程是有钟点的：基底层新生的细胞上移到颗粒层约需 14 天，再移到角质层表面并脱落又需 14 天，共约 28 天——这就是“表皮通过时间”（P66）。
图 D2 · 表皮五层动态迁移：如同婴儿长大，全程约 28 天
机制 · 因为表皮每 28 天整体换新一次，所以很多皮肤病（如银屑病）用药后，要等旧的“坏砖”随周期脱落、新的“好砖”长上来，才会肉眼见效——治疗的显效节奏，由这 28 天的生物学时钟决定。
2.3 表皮的三位“特殊员工”
表皮里80% 以上是角质形成细胞，但皮肤有了“砖块”还不够，还有着三位“特殊员工”，把皮肤从“砖墙”升级成“有智能的建筑”：
细胞 位置 干什么 生活里的对应
黑素细胞 基底层（约占 10%）+ 毛囊 合成黑素，经树突喂给周围 10～36 个角质形成细胞，组成“表皮黑素单位”；像给皮肤打伞，遮挡紫外线 肤色、晒黑、白癜风、黄褐斑、白头发
朗格汉斯细胞 表皮浅层（占 3%～5%） 免疫哨兵：识别、摄取、提呈抗原，是接触性皮炎等Ⅳ型超敏反应的始动者 为什么“新护肤品一用就过敏”
梅克尔细胞 基底层 与神经轴突组成复合体，专司机械触觉 指尖能摸出纹理、笔尖
2.4 五个生活场景，把结构“用”起来
生活场景 · 肤色：为什么有人白、有人黑，晒了太阳又会变黑
黑素细胞（画家）把黑素“搬运”给周围的角质形成细胞，构成一道紫外线防线——多了一道“防晒衣”，墙就多了抗晒的功能。这也解释了为何肤色、色斑，本质上是“结构（黑素分布）决定表现（颜色）”。

黑素细胞“多不多”，和肤色、人种、性别无关。 准确地说，黑素细胞数量与部位、年龄有关，但与肤色、人种、性别无关。决定你黑还是白的，不是“画家”（黑素细胞）的数量，而是角质形成细胞里黑素小体的数量、大小与分布。换句话说：不是画家多少不同，而是有人颜料蘸得浓、有人蘸得淡。

为什么晒太阳会变黑？ 紫外线一照，黑素细胞就“加班”合成更多黑素，像给每层砖都刷上一层防晒漆——这是皮肤的自我保护。所以晒黑不是“脏了”，是皮肤在主动打伞。

白癜风 = 画家停工：局部黑素细胞受损“罢工”，那一片墙就褪了色；黄褐斑 = 颜料叠多了：局部色素沉积，“叠色”变深。

白头发 = 毛囊里的画家退休了：头发之所以是黑的，靠的是毛囊中的黑素细胞持续供“颜料”；随着年龄增长，这些黑素细胞活性下降、数量减少，颜料供不上，头发就由黑转白——这是生命时钟在头发上的显形。
图 2-3 · 黑素细胞电镜照片，K 为角质形成细胞，N 为黑素细胞核（引自《皮肤性病学》第10版）
生活场景 · 烧伤：伤在哪一“层”，决定留不留疤
表皮没有血管，营养靠基底膜带从真皮“渗透”上来（P134）。所以：
浅度烧伤只伤及表皮 → 基底层还在 → 能自己长好、一般不留疤；
一旦深达真皮乃至皮下 → 基底层被破坏 → 需要靠瘢痕修补、留疤甚至影响功能。
机制 · 结构决定功能：同样是“烧伤”，伤在表皮还是真皮，结局天差地别。这也解释了为什么深度烧伤要植皮——因为“产房”（基底层）没了，墙体无法自愈。
生活场景 · 头发：每根头发都有自己的“人生阶段”
毛囊里的毛母质不断分裂，头发便长出来。但它们不是同步的：每根头发在生长期（约 3 年）→ 退行期（约 3 周）→ 休止期（约 3 个月）之间循环，全部头发约 80% 处于生长期；正常人每天脱落 70～100 根，同时有等量的再生（P181）。
图 2-6 · 毛发及毛囊结构模式图（引自《皮肤性病学》第10版）
所以“掉头发”不一定是病。只要脱落与新生大致持平，就是正常的新陈代谢——掉，是因为另一根正在“出生”。若脱落明显多于新生，才进入真正的脱发进程。（还记得吗？毛囊里的黑素细胞退休，头发就白了。）
生活场景 · 出汗：皮肤是人体的“散热系统”
汗腺分两型（P193–195）：
外泌汗腺（小汗腺）：遍布全身，受交感神经胆碱能（乙酰胆碱）支配，分泌 99% 是水分的清淡汗液；按诱因分温热性（气温 >31℃ 显性出汗）、精神性（紧张时掌跖前额冒汗）、味觉性（吃辣出汗）。
顶泌汗腺（大汗腺）：分布在腋下、乳晕等处，受去甲肾上腺素支配，青春期才旺盛，主要与体味和信息素传递相关，而非体温调节；分泌液体本身无味，是被皮肤表面的细菌酵解后才产生臭味（这就是腋臭的来源）。
体味从何而来？ 顶泌汗腺是关键一环，但并非唯一决定因素——一句话概括：汗液本身基本无味，气味来自细菌的分解。
1. 顶泌汗腺（主料）：腋窝、腹股沟等处分泌的汗液含蛋白质与脂质，被皮肤表面细菌分解后产生特征性气味；其数量、活性与成分先天因人而异。
2. 小汗腺（助燃）：遍布全身、分泌水样汗，主司体温调节、通常无味，但大量出汗会“加湿”，助长细菌繁殖、加重体味。
3. 皮肤菌群（加工者）：棒状杆菌、葡萄球菌等分解汗液中的有机物，产生挥发性物质——这是体味的直接来源。
4. 饮食代谢与激素（变量）：大蒜、洋葱、辛辣食物及体内代谢产物可经汗液排出而改变气味；青春期与内分泌变化会增强顶泌汗腺活动。

不同人群的顶泌汗腺活性与菌群组成可有统计学差异，但个体差异远大于群体差异，卫生习惯、衣着等生活方式同样影响明显——体味终究是生理、微生物、环境多因素交互的结果。
机制 · 结构决定功能：皮肤通过皮下血管丛的“扩张散热 / 收缩保温”和汗腺蒸发，维持体温恒定。天热时全身靠汗液蒸发散热，正是这套“散热系统”在干活。
生活场景 · 纹身与洗纹身：墨水为何“焊”在身上，又如何被清走
把刚学的结构用起来，就能看懂纹身的底层原理——它是一堂活的“真皮结构 + 皮肤免疫”课：

纹身为什么（基本）洗不掉？ 文身针把色素注入真皮（在表皮下方、基底膜带之下）。关键在此：我们前面说过，表皮每 28 天整体翻新一次——可真皮不参与这种“大换血”，它靠胶原与基质缓慢代谢，更新以“年”计。于是沉在真皮里的色素颗粒，被局部的巨噬细胞、成纤维细胞包裹住、原地“封存”，既不随表皮脱落、也不被很快清除，就成了长期印记。

洗纹身为什么能“碎”掉，却又很慢？ 激光洗纹身用的是“选择性光热作用”——特定波长的光被色素颗粒吸收、瞬间把它爆破成细小碎片；这些碎片再由真皮里的巨噬细胞吞噬，经淋巴系统慢慢运走。所以“洗纹身”本质上是借皮肤的免疫功能（巨噬细胞）来清运垃圾。之所以要多次、间隔进行，是因为一次只能打碎并清除一部分，残余色素还会重新聚拢——这又回到结构：真皮代谢慢，清运自然也慢。
图 D4 · 纹身与洗纹身原理：真皮沉积 → 免疫封存常驻；激光碎裂 → 巨噬细胞清运
提醒 · 把原理讲清，也得把分寸说到位：纹身与洗纹身都是有创操作。社交平台上，纹身常被包装成“彰显个性”的符号，但请冷静看清——看似特立独行，有时只是另一种从众：冲动跟风、盲目下针，伤的终究是自己的身体；若器械消毒不严，还可能把血源性病原体（乙肝、梅毒、HIV 等）直接带进体内。此外，洗纹身疼痛、价高、且常难彻底清除（尤其彩色、深色），还可能留疤或色素沉着；未成年人、瘢痕体质、免疫力低下或孕期人群更需谨慎。以上不是诊疗建议，具体情况请到正规医院皮肤科 / 医疗美容科咨询。
2.5 七大类功能，一条主线收束
教材把皮肤功能归为七类：屏障、吸收、感觉、分泌和排泄、体温调节、代谢、免疫（P37–40）。它们看似繁多，却都能用一句话收束——结构是功能的地基，功能是结构的用途。逐一来看：
1. 屏障功能：靠角质层“砖墙”（角质细胞 = 砖，细胞间脂质 = 灰浆）+ 弱酸皮脂膜，挡住物理摩擦、化学刺激、微生物入侵，并防止水分与电解质丢失（成人每天不显性失水 240～480 ml）。表皮完整 → 微生态平衡；屏障破坏 → 炎症。
2. 吸收功能：主要经角质层（其次毛囊、汗管）经皮吸收，是外用药治疗的通道。吸收强弱受部位（阴囊最易、掌跖最难）、水合程度（封包可使吸收增高约 100 倍）、物质理化性质等影响。
3. 感觉功能：有触、痛、压、冷、温等单一感觉，也有潮湿/坚硬/柔软/粗糙/光滑等复合感觉，以及两点辨别、定位觉。其中痒觉是皮肤黏膜特有的感觉，且无专门感受器——它驱动搔抓，是许多皮肤病的主诉。
4. 分泌和排泄功能：小汗腺排汗（水分 99% + 电解质，酸性 pH 4.5～5.5）散热排废；大汗腺（青春期旺盛）分泌物经细菌酵解产生气味；皮脂腺分泌皮脂润泽皮肤（受雄激素调控）。
5. 体温调节功能：通过皮下血管“冷缩热张”与汗腺蒸发双向调控——环境温度过高时，主要靠汗液蒸发散热。
6. 代谢功能：表皮糖代谢以无氧糖酵解为主（仅在相对缺氧下高效增殖）；还参与蛋白质（角蛋白、胶原）、脂类（屏障成熟、日光下合成维生素 D）、水电解质代谢（急性炎症时皮内水钠增加，故需适当限盐）。
7. 免疫功能：1986 年提出的“皮肤免疫系统（SIS）”——角质形成细胞分泌细胞因子与抗菌肽、朗格汉斯细胞提呈抗原、T 细胞与肥大细胞驻守，构成接触性皮炎、银屑病等免疫性皮肤病的共同舞台。
机制 · 主线回扣：七类功能，七种“结构→功能”的映射——砖墙→屏障、角质层通道→吸收、神经末梢与梅克尔细胞→感觉、汗腺皮脂腺→分泌排泄、血管丛→体温调节、活跃的代谢酶系→代谢、朗格汉斯与角质形成细胞→免疫。
三、临床表现：从“机制”推演“长相”
皮肤病的“长相”叫皮损。临床表现 = 症状（患者主观感受，如瘙痒、疼痛）+ 体征（客观可见可触的皮损）（P42）。
辨析 · 皮损 ≠ 皮疹（两个不同层次的概念）：
皮损（skin lesion） 是具体的“病变单位”——单个或局限的皮肤异常改变，是皮肤科描述的基本零件。本文 §3.2、§3.3 列出的 18 种（原发 8 + 继发 10），每一个都是皮损。
皮疹（rash） 是一个描述性术语，指皮肤上成片或广泛出现的一系列皮损，通常由多种皮损混合构成。例如“麻疹样皮疹”是许多红色斑丘疹的集合，“猩红热样皮疹”是弥漫性红斑 + 丘疹的组合。
一句话分清楚：皮损是“砖块”，皮疹是“砖墙”——皮疹不是一种独立的皮损类型，而是对“一组皮损的分布与外观”的宏观描述；因此在专业分类里，皮疹不单列为一类皮损。
注意：这里“砖墙”的比喻，呼应了前面“皮肤是一堵墙”的说法，但用的是不同层级——前者讲单个皮损的形态（墙上的某个问题），后者讲许多皮损如何拼成一片成片的图景。两个比喻，互不冲突。
3.1 机制→表现的核心逻辑链
机制 · 皮损不是凭空长的。它的形态，由“谁、在什么层次、干了什么”决定。
举一个例子——结节（nodule）：
机制：结节由真皮或皮下组织的炎性浸润、代谢产物沉积或组织增生引起（P44）。
表现推导：因为它长在组织深层（真皮/皮下），所以——可能隆起于皮面，也可能不隆起；但一定能摸得到，呈圆形或椭圆形，有一定硬度或浸润感。
图 4-4 · 结节和囊肿 A.结节；B. 囊肿。（引自《皮肤性病学》第10版）
机制 · 结节就像地里钻出的地鼠——它可以把头探出地面（隆起），也可以缩在土里只顶起一小包（不隆起），但你蹲下用手一摸，就能感觉到那团硬硬的“住户”。所以判断结节，靠的是“看不见，但摸得到”。对比囊肿：它有深在的囊性感，但囊肿有囊腔、触之囊性感（像小水袋），而结节是实心的硬。一实一囊，手感不同。
3.2 原发性皮损：皮肤自身直接的问题（以墙为喻）
原发性皮损（8 种）是组织病理变化直接产生的；如果把皮肤看成一堵墙，那原发性皮损就好比是这堵墙因为各种病因直接表现出来的问题。而继发性皮损，是在原发性皮损基础上，经过一段时间、或受外界影响（如人为搔抓、治疗不当）所导致的。
下面给每一种原发性皮损打一个比方——前提：皮肤好比是一堵墙。
斑疹 / 斑片 = 墙上某块“刷了颜色”。 表面平平的，只是颜色变了（红、褐、白），摸不到。≤1 cm 叫斑疹，>1 cm 叫斑片。比如过敏的红片、白癜风的白斑。
机制 · 回扣：斑疹“摸不到”，是因为它只是局部毛细血管扩张或色素改变，没有实质性隆起——只是墙刷了漆，墙面没鼓。
丘疹 = 在墙面上“抠了一粒鼻屎”（请原谅这个粗粝但难忘的比方）。 它是表浅、实质性、能摸到的隆起，≤1 cm。比如粉刺、扁平疣的小疙瘩。
机制 · 回扣：丘疹“能摸到”，是因为病灶在表皮或真皮浅层（细胞增殖、炎症浸润）——墙面真的鼓了个小包。
图 4-1 · 斑疹和丘疹 A.斑疹；B. 丘疹。（引自《皮肤性病学》第10版）
斑块 = “一整片鼻屎连成、或几个丘疹抱团长大”的一块补丁。 它和丘疹同源，只是 >1 cm、表浅、实质性。比如银屑病的大块红斑。
风团 = 墙皮下“被快速吹起的一个装水（其实是组织液）的气球”。 红或苍白色、周边红晕，来得猛、此起彼伏，几小时就瘪平、不留痕迹——荨麻疹的招牌。
机制 · 回扣：风团是真皮浅层小血管通透性升高 → 局限性水肿，所以“鼓得快、消得快、退无痕”，像气球漏了气。肥大细胞就驻守在真皮乳头血管周围，是这一幕的“主角”。
图 4-2 · 斑块和风团 A.斑块；B. 风团。（引自《皮肤性病学》第10版）
水疱 / 大疱 = 墙皮底下“进水了”。 ≤1 cm 叫水疱，>1 cm 叫大疱，装血叫血疱。疱壁厚薄取决于位置：角质层下最薄（白痱），棘层略厚（水痘），表皮下最厚（类天疱疮）。
脓疱 = “墙里长了颗化脓的粉刺白头”。 隆起的腔隙里包着脓液，周边常有红晕。注意：脓疱不等于感染——脓疱型银屑病是无菌的；水疱被细菌攻陷变脓，也可成“继发性”脓疱。
图 4-3 · 水疱和脓疱 A.水疱；B. 脓疱。（引自《皮肤性病学》第10版）
结节 = 墙里“住了只地鼠”（见 3.1 与图 4-4）。它在深层，可探头可不探头，但摸得到、有硬度。
囊肿 = 墙里“埋了个带囊袋的小水球 / 油包”。 有囊腔结构，摸着囊性感（像包着水的软气球），可隆起也可只摸得到。比如表皮囊肿。
机制 · 同样是“红”，斑疹只在皮下变色、丘疹在表面鼓包、水疱在皮里积水、结节在深处长实——层次的差异，直接决定手感与长相的不同。这就是“结构/位置决定表现”的集中体现。
3.3 墙坏了之后：继发性皮损的“修补比喻”
继发性皮损（10 种）是原发性皮损演变而来，或搔抓、治疗不当“人为造成”的。它们像墙破损、修补后留下的各种痕迹——
糜烂 = 墙皮表层“被蹭掉一块，露出里面红红的底”。 只伤到表皮，没动到地基（基底层），能自己长好、一般不留疤。常由水疱/脓疱破裂、浸渍脱屑而来。
溃疡 = 墙“从皮面一直塌到地基以下、挖了个深坑”。 全层缺损累及真皮甚至皮下，得用瘢痕填补，会留疤、愈合慢。感染、肿瘤、血管炎都可引起。
机制 · 回扣：糜烂 vs 溃疡，本质是“伤没伤到基底层”——没伤→自愈无疤；伤了→瘢痕修补。这也是判断预后（会不会留疤）的关键。
图 4-5 · 糜烂和溃疡 A.糜烂；B. 溃疡。（引自《皮肤性病学》第10版）
鳞屑 = 墙皮“一片片翘起、掉白屑”。 像受潮起皮的墙面、或头上的头皮屑。源于角质形成过快或角化异常。
浸渍 = 墙角“长期泡水发白变软起皱”。 像泡久了的手指肚。继续摩擦 → 表皮脱落 → 露出糜烂面 → 易继发感染。
图 4-6 · 鳞屑和浸渍 A.鳞屑；B. 浸渍。（引自《皮肤性病学》第10版）
裂隙 = 墙“干裂出一道缝”。 线状裂口，深可达真皮，像旱季的河床、冬天手上的裂口。源于干燥、增厚、弹性下降后被牵拉。
瘢痕 = 墙修补后“留下的补丁”。 增生性 = 鼓起的暗红无毛补丁；萎缩性 = 凹陷的补丁；瘢痕疙瘩则是补丁“越长越出圈（蟹足样）”、超出原伤口。
图 4-7 · 裂隙和瘢痕 A.裂隙；B. 瘢痕。（引自《皮肤性病学》第10版）
萎缩 = 墙“越来越薄、塌下去”（材料不够）。 半透明、纹理变浅，像磨薄的羊皮纸；可发生在表皮、真皮或皮下。
痂 = 墙上的“血 / 脓 / 浆干了结成的硬壳”。 由皮损表面的液体（浆液、脓液、血液）与脱落组织或药物等混合凝结而成，像伤口结的痂。颜色对应成分：黄 = 浆性，绿 = 脓性，黑红 = 血性。
图 4-8 · 萎缩和痂 A.萎缩；B. 痂。（引自《皮肤性病学》第10版）
抓痕 = 墙被“指甲挠出的几道印 / 划痕”。 线状或点状表皮剥脱，源于搔抓摩擦——皮肤的“自残痕迹”。
苔藓样变 = 墙被“反复摩擦长出老茧 / 树皮般的厚皮”。 皮嵴隆起、皮沟加深、皮革样、剧痒。它是“痒→抓→厚→更痒”恶性循环的产物，是继发性而非原发的。
图 4-9 · 抓痕和苔藓样变 A.抓痕；B. 苔藓样变。（引自《皮肤性病学》第10版）
机制 · 这 10 种“修补痕迹”，无一不是“墙先破了，才有的后续”。比如浸渍久了 → 掉皮 → 糜烂；反复抓 → 增厚 → 苔藓样变。
3.4 四步拆皮损：生活中的快速辨别法
遇到一个不认识的皮疹，不用背字典，用下面这条四步鉴别链现场拆解（P42–44）：
图 D3 · 四步拆皮损鉴别链
口诀 · 平不平？实不实？深不深？过没过一厘米？
1. 平不平？ —— 平齐、摸不到 → 斑疹 / 斑片（只是颜色变了）；隆起 → 进入下一步。
2. 实不实？ —— 实质性硬疙瘩 → 进入第 3 步；腔隙性（鼓包里含水/脓）→ 水疱 / 大疱 / 脓疱 / 囊肿。
3. 深不深？ —— 表浅（真皮浅层）→ 丘疹 / 斑块；深在（真皮/皮下）→ 结节 / 囊肿。
4. 过没过一厘米？ —— 这是“分大小”的尺子：斑疹 ↔ 斑片、丘疹 ↔ 斑块、水疱 ↔ 大疱，都以 1 cm 为界。
顺手记几个“家族成员”：风团是“来也匆匆去也匆匆、几小时消退不留痕”的水肿性隆起（荨麻疹的标志）；抓痕与苔藓样变是“痒→抓”链条的两端。
需要提醒的是：这四步法帮你“初步归类”，但归类不等于诊断。同一种皮损可以出现在几十种病里，真正下结论，还要结合部位、分布、病史和辅助检查（第五章起才会讲）。把它当“观察的起点”，而非“确诊的终点”。
一页纸小结
模块 核心结论 记忆钩子
皮肤病与性病 性病学 ⊂ 皮肤病学；三种思考：内病外显 / 隐秘外显 / 潜伏时间差 有诸内者，必形诸外
皮肤结构 表皮/真皮/皮下 + 基底膜带；表皮五层同源 砖墙 + 钢筋网 + 地基
表皮其他细胞 角质形成细胞 + 黑素/朗格汉斯/梅克尔；肤色 = 黑素分布，与黑素细胞数量无关 晒黑=打伞，白癜风=停工，白头发=画家退休
表皮动态 角质形成细胞由基底层向上迁移，约 28 天一轮 婴儿→退休，28 天
五种生活绑定 肤色看黑素小体不看细胞数；烧伤看层次定留疤；头发 3 年/3 周/3 月；汗腺是散热系统；纹身沉真皮+免疫封存、激光碎裂靠巨噬细胞清运 掉发≠病，天热靠蒸发；墨水沉真皮→难褪
七大类功能 屏障/吸收/感觉/分泌排泄/体温调节/代谢/免疫，皆“结构→功能” 结构是地基
皮损逻辑 机制→表现；全部 18 种皮损均有“墙”的比喻 平？实？深？1cm？
一句话总纲：结构是功能的地基，机制是表现的源头；把皮肤想成一堵会新陈代谢的活墙，大多数“长相”都能倒推回去。
写在最后
皮肤是最诚实的器官——内在的病，终会在体表显形；而性病的“内隐外显”与“潜伏时间差”，恰恰提醒我们别把沉默当作安全。
疾病的“内隐外显”，提示预防远比补救重要——洁身自好是底线，而一旦有暴露风险，别让羞耻耽误了早筛查。今天学的四步拆皮损，是“观察的起点”而非“确诊的终点”。
